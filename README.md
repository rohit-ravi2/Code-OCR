# Code-OCR

A small tool from 2022 for reading source code out of images (.jpg, .png) and returning it as plain text. The goal was to handle the cases where general-purpose OCR breaks on code: indentation, similar-looking characters such as `0`/`O` and `1`/`l`/`I`, and brackets and punctuation.

The original code was not kept, so this repo holds only this description.
